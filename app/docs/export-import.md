# Export, import, and local projects

For functional apps built in Make, see [download runnable source ZIPs](make-source-export.md).

Use **Export** in the header to open the export studio. Choose **SVG**, **PNG**, **WebP**, or **PDF**, then select any combination of **1×, 2×, and 3×** scales, independently of editor zoom. Choose a transparent background or Paper cream. Selected frames export at their artboard size; the whole canvas covers visible artwork. Rulers, grid, selection handles, labels, and editor chrome are excluded.

**Artboards** exports visible top-level frames as separate assets. **Selection** combines the selected layers into one asset. **Selected layers** exports each selected root separately, deduplicating descendants of selected frames. **Whole canvas** exports a single composition. Check the artwork to include and click a row to preview it. The live preview follows artwork, format, background, gamut, and WebP quality changes; it is capped at 480 px and debounced to keep editing responsive. Changing output scale updates dimensions without rerendering the thumbnail.

More than one asset or scale downloads a **ZIP archive** containing named files with `@1x`, `@2x`, or `@3x` suffixes and a `manifest.json` describing each asset's dimensions, scale, color space, and background. Duplicate names receive numeric suffixes. Exports use one immutable scene revision, render sequentially, and never change selection or history. A progress indicator and **Cancel export** control are available while preparing a batch. Batches are limited to 999 assets and 512 MB.

SVG uses native geometry and text, with nested frame transforms, clipping, opacity, strokes, shadows, and rounded corners. Scale changes intrinsic SVG dimensions while retaining the viewBox and editable paths. Images are embedded. Shader fills are rendered at their saved static frame and embedded as PNG snapshots, including offscreen shader layers. WebGL 2 is required to export shaders. Text remains text and uses the system fonts available in the exporting browser; viewing an SVG elsewhere requires the same fonts.

PNG is lossless and offers **sRGB** or **Display P3** where the browser supports a P3 canvas; unsupported P3 is disabled instead of silently changing colors. Rasterization converts CSS paints to the chosen output gamut, and the browser encodes the PNG color profile. SVG retains original CSS colors. WebP uses sRGB with adjustable quality (10–100%, default 92%) and retains alpha transparency. Browsers without a WebP encoder report an error rather than downloading a PNG with a WebP extension. PNG and WebP output are limited to 64 megapixels and 16,384 pixels per side.

PDF embeds a lossless sRGB raster of the artwork and an alpha mask when needed. It preserves the visual composition, including shaders, rather than editable PDF paths. The page follows artwork dimensions at 72/96 points per CSS pixel, regardless of scale; scale controls the embedded image resolution. PDF output is limited to 16 megapixels and 16,384 pixels per side to bound RGB and alpha buffer memory. No CMYK or print proofing conversion is performed.

**Save project JSON**, the export studio's **Save project JSON** action, or **⌘/Ctrl S** downloads a versioned `.paper.json` file with every layer, frame hierarchy, shader parameters, project name, camera, and grid preference. **Open or import file** opens Paper project JSON (including legacy scene JSON). SVG and HTML files are inserted into the current document. Project JSON preserves image source URLs; external images must remain accessible when reopening it.

Changes are saved in IndexedDB after a short idle period, and restored on reload. Open the project switcher beside the document name to create, search, switch, or rename local projects. Each project retains its own artwork, camera, and grid setting. Paper saves the outgoing document before switching and resets editing history for the newly opened project. Existing single-document local-storage saves are migrated on first launch; the original copy is retained for recovery. Download JSON for a portable backup. If storage fills up or is unavailable, the header asks you to save JSON.

The avatar in the header opens **Profile & account**. Set a display name, upload a local avatar, name your workspace, choose studio appearance, and set the engineering grid default for new projects. Account changes apply when saved; cancel discards the draft. The profile is stored separately from canvas projects in this browser's local storage and is never included in project JSON or artwork exports.

The **Local MCP auth token** field can store an existing token or generate a cryptographically random token for your own self-hosted MCP gateway. Reveal, copy, regenerate, or remove it in account settings, then save the changes. Paper does not send this value anywhere or configure gateway authentication. The bundled localhost bridge and stdio server do not require this token. Agents edit the active canvas directly by default; explicit `--file` mode edits exported `.paper.json` files. See [live MCP setup](live-mcp.md). MCP design tokens are separate from gateway authentication.

Paste with **⌘/Ctrl V** while working on the canvas:

- **SVG:** SVG markup, SVG clipboard data, or an SVG file is inserted as a vector-backed image layer. Paths, transforms, gradients, masks, and local references remain scalable. SVG internals are not separate editable Paper layers.
- **Figma:** use **Copy as SVG** in Figma, then paste into Paper. Figma's private binary clipboard format and `.fig` files are not supported.
- **HTML:** HTML clipboard fragments or raw HTML markup become an editable frame containing rectangle, text, and embedded raster-image layers. Layout is measured in an isolated, script-free document. Inline layout styles, solid backgrounds, borders, corner radii, opacity, and typography are supported. External stylesheets, CSS classes, gradients, complex effects, and remote HTML images are not imported.

Pasted artwork is centered in the visible canvas and selected as one import. Ordinary text input fields retain their native paste behavior. SVG scripts, event handlers, foreign objects, animation, external resource references, and HTML executable content are stripped. Files are limited to 16 MB; malformed documents are rejected before they change the current scene.
